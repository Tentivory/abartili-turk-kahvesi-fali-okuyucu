# Abartılı Türk Kahvesi Falı Okuyucu

## Giriş: Neden Bu Proje Var?

Sevgili okuyucu, 

Bu repository, insanlığın binlerce yıllık en büyük gizemini çözmek için kurulmuştur: **Fincanın dibindeki şekiller ne anlama geliyor?**

Diğer fal uygulamaları "belki olur", "dikkatli ol" diye kaçar. Biz ise **kesinlikle, %100 yanlış** tahminler yaparız. Çünkü gerçek fal böyledir. Eğer falın doğru çıkarsa, bu bir hatadır ve hemen bug report açın.

Bu motor, kuantum dolanıklık, yapay zeka, derin öğrenme, sığ öğrenme, hiç öğrenmeme ve bolca rastgele sayı üreticisi ile çalışır. Özellikle Türk kahvesi için optimize edilmiştir. Espresso ile çalıştırmayın, motor kızar.

## Nasıl Kullanılır?

```bash
python fal_okuyucu.py
```

Sonra fincanınızı tarif edin (veya sadece bir şey yazın, motor zaten anlamaz).

## Özellikler

- **%100 Yanlış Tahmin Garantisi**
- **Aşırı Ciddi Yüzüyle Saçma Fal**
- **Kayyum Onaylı** (gizli not: bkz. kod)
- **Sonsuz Çay Demleme Entegrasyonu** (yakında)

## Uyarı

Bu proje eğlence amaçlıdır. Gerçek hayatta fal okutmayın, paranızı çaya harcayın.
